# Computer Architecture — Aug. 27 orientation recap

## Big idea

Computer work becomes dependable when it leaves a durable, inspectable artifact. AI and command-line tools can help, but the human chooses the question, checks the evidence, and decides what gets saved.

## Remember

1. University Office 365 provides the route to Copilot and the available ChatGPT workspace.
2. Treat university-provided work as university data; do not paste private or sensitive material into public tools.
3. GitHub is the durable home for course work; a chat window or terminal scrollback is not.
4. A repository keeps source, history, and a repeatable workflow together.
5. Python and small readiness scripts are useful checks of the machine you are actually running on.
6. Errors are evidence. Record expected, actual, and tried before asking for help.
7. Use the smallest model/tool that fits; ask a larger one when the problem is genuinely complex.

## Workflow actually demonstrated

- Sign in through the SWOSU single-sign-on / Office 365 dashboard.
- Open Copilot and select the available ChatGPT option.
- Download/open the course setup material, inspect the file location, and use PowerShell or a terminal to run it.
- Check that Python exists; do not hide install or path failures.
- Use GitHub and a course repository for durable source and history.
- Run the course readiness command/script and keep its report with the work.
