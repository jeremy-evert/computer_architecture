# Computer Architecture Sidecar Prompts

Project-local Foreman work orders for getting COMSC-3013 ready for Fall 2026 deployment.

## Contract

- Open work orders live in this directory.
- Completed/accepted work orders may later move to `completed/` when that convention is established here.
- Each prompt writes its evidence/report to `sidecar/reports/NNN_<slug>.md`.
- Foreman may dispatch bounded workers/golems, but no worker self-certifies completion.
- Course truth belongs outside `sidecar/`; process notes, execution evidence, and unresolved work belong inside it.
- Git is authoritative. Savnac is the inspection/dogfood surface. Production SWOSU Canvas writes require explicit authorization.
- Required course work must not depend on purchasing commercial textbooks, zyBooks, paid AI subscriptions, premium AI CLI tools, or specialized GPU hardware.
