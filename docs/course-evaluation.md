# Course evaluation - 2% gradebook object

This file exists so the accepted 2% **Course evaluation** grading category has a truthful Canvas source object.

The actual university course-evaluation instrument is administered outside this course's own authored Canvas assignments. This course object is therefore a **gradebook-only completion-credit placeholder**, not a second survey.

## Canvas mechanics

- assignment group: `Course evaluation`;
- grading type: points;
- points possible: 2;
- submission type: `none` / no student artifact submitted to this assignment;
- completion credit is instructor-entered or handled by the institution's approved process.

## Explicit non-goal

Do not invent an API integration, duplicate evaluation survey, proof screenshot, or anonymity-breaking completion tracker merely to automate these two points.
