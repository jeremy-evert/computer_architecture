# Week 5 - Build the Machine (Sep 14-18)

## Status
Accepted spine and dossier role; lecture, PC-build activity, data sources, plotting/report scaffolds, and validation still need authoring.

## Weekly Focus
**What should I build for this workload, what does each part buy me, and how should I compare choices?**

This is the first real Architecture week. Students stop preparing the laboratory and begin using it.

The goal is not component identification. Students should connect compatibility, workload fit, cost, hierarchy, and constraint.

## Monday - Think / Frame / Lecture
**AI Fluency Lens 5: Select the Right Model.**

Lecture: **Build the Machine.**

Frame the computer as a set of negotiated constraints rather than a collection of named boxes. Introduce workload-driven component choice and the danger of choosing a metric before deciding what matters.

## Wednesday - Investigate / Break / Measure
**Professional Minds: _The Art of Thinking Clearly_ - How do we avoid common thinking mistakes?**

PCPartPicker-style laboratory:

1. **Would It Run?** Build a compatible functioning system.
2. **Would It Be Fun / Fit the Workload?** Spend the budget around a stated use case.
3. **Dollars Per.** Begin quantitative comparison of capacity/cost from cache outward through RAM and storage, with network/cloud where appropriate.
4. Capture an observable real-machine snapshot using `archprobe` or the validated Prompt 003 equivalent when available.

## Friday - Explain / Defend / Stack Showcase
**Professional Minds: _How Not to Be Wrong_ - How do we avoid common thinking mistakes?**

Defend one design choice and identify one naive metric that may be useful but incomplete or misleading.

**Stack Showcase:** Jeremy opens one of his real machines as a design artifact: what was bought, what workload it serves, where money went, and what tradeoffs were accepted.
