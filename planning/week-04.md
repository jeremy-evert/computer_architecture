# Week 4 — Linux Command Line as a Machine Telescope (Sep 8–11)

## Status
Short Labor Day week. Pinned focus; exact command set/activity still needs validation in the supported lab image.

## Weekly Focus
Use Linux and command-line tools to ask the machine questions and collect evidence. Commands are taught as observation instruments, not as detached memorization.

## Monday — Sep 7 — Labor Day
No Monday requirement. Frame material may open asynchronously without creating extra holiday load.

## Wednesday — Sep 9 — Inspect / Build / Measure
Inspect files, processes, CPU/memory/system information, and binaries using a validated subset of tools such as `file`, `uname`, `lscpu`, `free`, `ps`, `/proc`, `xxd`/`od`, compiler output, and disassembly tools.

## Friday — Sep 11 — Explain / Defend
Choose one machine fact and explain how the command output supports the claim. Separate observation from interpretation.

## Evidence this week
A short machine-observation receipt containing commands, relevant output, and an evidence-backed explanation of what the student learned about the system.
