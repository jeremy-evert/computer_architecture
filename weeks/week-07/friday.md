# Week 7 Friday - Explain / Defend

## Professional Minds

*Rethinking Grading*. Use the question: what evidence demonstrates that someone understands execution rather than remembers labels?

## Receipt

1. State the deliberate trace error or ambiguity.
2. Correct it using the instruction's ISA promise and the bounded datapath.
3. Explain why each major structure/control choice in the corrected path is necessary.
4. Identify the architectural state that changes.
5. State one way a modern real CPU can implement the same promise differently.
6. If AI/retrieval produced a different datapath explanation, classify whether the disagreement was factual or a scope/model mismatch.

Raw component labeling is insufficient.
