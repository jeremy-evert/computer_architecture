# Instructor plan - Week 4

## Monday

Labor Day. No recording or student requirement.

## Wednesday recording / canonical run

1. Open with one vague question: "what is this computer doing?"
2. Decompose it into observable subquestions.
3. Run `archprobe` first so evidence scope is visible.
4. Add a few Linux instruments (`uname`, `lscpu`, `free`, `ps`, `file`, `od`).
5. Put one raw observation next to one interpretation and one limitation.
6. Stop before the session becomes a shell-command catalog.

## Friday Stack Showcase

Ask the same machine question on an instructor-owned Linux system or another environment and show how the tools/evidence scope differ. This is enrichment, not a student requirement.
