# Instructor plan - Week 2

## Monday recording spine

1. Open with the machine question.
2. Demonstrate a confident AI answer to a bounded machine question.
3. Put Question / Proposal / Evidence / Conclusion on screen as four separate boxes.
4. Run one independent machine command.
5. Revise the original statement visibly.
6. Show the no-account fallback so students know paid AI is not a gate.
7. End with: what evidence would make you change your mind?

## Wednesday canonical demonstration

Use the standard-library command in `wednesday.md` on the recording host. If useful, contrast it with `uname -m` or a VM/container/WSL view.

Expected shape: observations agree on some facts while environment/scoping language remains important.

## Friday Stack Showcase

Compare two AI tools on the same bounded technical question, then verify both against one primary/machine evidence source. Provider comparison is instructor enrichment only.
