# Week 2 - AI Laboratory Training

> **Central machine question:** How can AI help me investigate a machine without becoming my source of truth?

## Week at a Glance

**Prior belief we are testing/refining:** if an AI answer sounds technical and confident, it is probably safe to treat it as the answer.

**Prediction before measurement:** write one bounded claim about the computer you are using and predict what evidence would confirm or reject it.

**AI Fluency:** Lenses 1 + 2 - Define the Problem + Gather Context.  
**Professional Minds:** Wednesday - *Make It Stick*; Friday - *Mindset*.

| Day | Mode | What happens | Evidence |
|---|---|---|---|
| Monday | Think / Frame | Separate proposal, observation, evidence, and conclusion | bounded question + evidence plan |
| Wednesday | Investigate / Break / Measure | Ask an AI tool or use the provided fallback claim, then verify against the machine | AI investigation receipt |
| Friday | Explain / Defend | Explain what changed after verification | evidence-backed revision |

## Continuity

- any AI assistant you can access **or** the provided no-account fallback claim;
- no paid AI, premium CLI agent, GPU, private host, or commercial textbook required.

## Scope

**This week is about:** asking a precise technical question and verifying a proposed answer.

**This week is not trying to teach:** prompt tricks, benchmark tuning, architecture theory, or loyalty to any AI provider.
