\ArchQuestionSlide{How can AI help me investigate a machine without becoming my source of truth?}{Choose one bounded machine claim and predict what evidence would confirm or reject it.}
\begin{frame}{Useful does not mean authoritative}\begin{itemize}\item AI can propose vocabulary, commands, hypotheses, and paths.\item A plausible explanation is not evidence.\item The machine and primary sources get a vote.\end{itemize}\end{frame}
\begin{frame}{Four boxes}\begin{enumerate}\item Question\item Proposal\item Evidence\item Conclusion\end{enumerate}\note{Keep these visibly separate in every technical investigation this semester.}\end{frame}
\begin{frame}{Make the question smaller}\begin{itemize}\item What OS is visible?\item What machine label is reported?\item How many logical CPUs are visible?\item What Python version is executing?\end{itemize}\end{frame}
\begin{frame}{Gather context before asking}\begin{itemize}\item Name the environment.\item State what you already know.\item Name what would change the answer.\item Ask for a testable proposal, not confidence theater.\end{itemize}\end{frame}
\begin{frame}{The fallback works too}\begin{itemize}\item No paid AI is required.\item No AI account is required for the reasoning task.\item A supplied model-like claim can be tested against evidence.\end{itemize}\end{frame}
\begin{frame}{Wednesday}\begin{itemize}\item Record one proposal.\item Run independent evidence commands.\item Compare proposal with observation.\item Revise the claim.\end{itemize}\end{frame}
\begin{frame}{Course rule}\centering\Large AI can propose.\\[1em]Evidence decides.\end{frame}
