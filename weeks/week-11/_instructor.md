# Week 11 instructor / recording plan

Begin from a Week 10 memory reference: `when the program uses this address, what does the address actually mean?`

Use one process-map example throughout. Demonstrate `getconf PAGESIZE` and a short `/proc/self/maps` excerpt. Explicitly label observation versus mechanism.

## Stack Showcase

Inspect a real process with `/proc`, debugger, profiler, or optional tracing. Comparing host/container/WSL views is excellent because it makes evidence scope visible.
